Como testar

Salvador abre automaticamente. Pesquise Recife, São Paulo e Brasília para verificar cidades brasileiras; pesquise Lisboa para uma cidade internacional. Experimente uma busca vazia e um nome inexistente para verificar os avisos. Use “Atualizar esta cidade” e compare duas cidades para conferir a atualização dos dados, do gráfico e dos cartões.
